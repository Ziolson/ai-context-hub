# 🧪 Phase 3: Test-Driven Development (TDD) Guide

> **Enforcing quality and preventing regressions through Red-Green-Refactor.**

---

## 🎯 Why TDD with AI Assistants?

AI tools naturally tend to patch errors at runtime by adding empty `try/catch` blocks or swallowing exceptions. 

Phase 3 prevents this by enforcing **Strict Red-Green-Refactor**:
1. 🔴 **Red**: Write a failing test for an acceptance criterion and confirm failure via terminal output.
2. 🟢 **Green**: Write the minimal code necessary to pass the test.
3. 🔵 **Refactor**: Clean up the architecture while ensuring all tests stay 100% green.
